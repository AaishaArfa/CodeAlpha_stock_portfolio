Stock Portfolio Maker

A simple Python-based Stock Portfolio Maker that allows users to enter stock names, quantities, and prices, and calculates the total investment value of the portfolio.

Features

- Add stock names and quantities
- Store stock details and prices
- Calculate the total portfolio value
- Display portfolio details
- Save portfolio data to a text file

Technologies Used

- Python
- File Handling
- Basic Python concepts

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure Python is installed on your system.
4. Run the Python program:

python stock_portfolio.py

5. Enter the required stock details when prompted.

Project Structure

├── stock_portfolio.py

Example

The program takes stock details such as:

- Stock name
- Quantity
- Price per stock

It then calculates the total value of the portfolio.

Total Value = Quantity × Stock Price
